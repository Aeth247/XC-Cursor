## 📖 使用指南

**使用说明**：解压后直接运行，绿色版无需安装。首次运行如被系统拦截，允许运行即可。

### 📊 账号管理
- **导入账号**：支持 JSON、CSV格式批量导入
- **分类管理**：右键设置标签，支持多标签分组
- **批量操作**：Ctrl+点击多选，支持批量删除、导出、激活
- **快速切换**：一键激活并切换到指定账号

### 🤖 自动注册
- **邮箱配置**：添加邮箱地址和授权码（非登录密码）
- **注册设置**：设置注册数量、间隔时间和并行数
- **开始注册**：点击开始后自动完成整个注册流程
- **进度监控**：实时查看注册进度和详细日志

### 🔧 常见问题
- **系统拦截**：Windows 点击"更多信息"→"仍要运行"；macOS 在安全设置中允许打开
- **注册失败**：检查网络连接，调整注册间隔，更换邮箱服务商
- **邮箱验证**：确认邮箱配置正确，检查垃圾邮件文件夹
