## 🎯 核心功能

### 📊 账号管理
- ✅ **批量导入导出** - 支持多种格式的账号数据
- ✅ **便捷打开主页** - 一键打开主页查看模型、设置限额
- ✅ **智能分类标签** - 灵活的账号分组管理，双击操作 
- ✅ **一键激活切换** - 快速切换不同账号，含机器码重置
- ✅ **查看模型详情** - 查看模型使用与订阅信息

- ✅ **模型支持** - 支持 Claude 4、GPT 5，完全免费使用

- ✅ **多域名轮换** - 随机选择域名，防止封号
- ✅ **自动绑卡** - 注册完成后自动绑定预设卡片
